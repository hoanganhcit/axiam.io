Getting Started

Create an application in your dashboard and integrate facial authentication into your web application.

1

Create Application

Login to your dashboard, go to Apps section, and click "Add New App" to create your application.

2

Get Credentials

Copy your API_KEY, SECRET_KEY, and Redis configuration from your application details page.

3

Embedded Widget (optional)

Add facial login to your website in 2 minutes with our ready-to-use widget.

4

Install Mobile App

Download Axiam mobile app for facial capture and device registration. Scan QR code to link with your account. 

// 1) Authenticate your application first
async function authenticateApp() {
  const response = await fetch('/api/v1/facial_sign_on/application_auth', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      api_key: 'your-api-key-here',
      secret_key: 'your-secret-key-here',
      domain: 'dashboard.axiam.io'
    })
  });

  const data = await response.json();
  return data.data.authenticated_token;
}

// 2) Request facial sign-in (sends push notification to user's mobile)
async function requestFacialSignIn(userUid, authToken) {
  const response = await fetch('/api/v1/facial_sign_on/login/push_notification', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${authToken}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ id: userUid })
  });

  const data = await response.json();
  return data.data.verification_token;
}

// 3) Listen for authentication result via ActionCable
function subscribeFacialSignIn(verificationToken) {
  const cable = ActionCable.createConsumer('wss://dashboard.axiam.io/cable');

  cable.subscriptions.create({
    channel: 'FacialSignOnLoginChannel',
    verification_token: verificationToken
  }, {
    received: function(data) {
      if (data.status === 'verified') {
        console.log('User authenticated successfully!');
        window.location.href = '/dashboard';
      } else if (data.status === 'failed') {
        console.log('Authentication failed');
        alert('Facial authentication failed. Please try again.');
      }
    }
  });
}

// Complete workflow example
async function startFacialAuth(userUid) {
  try {
    const authToken = await authenticateApp();
    const verificationToken = await requestFacialSignIn(userUid, authToken);
    subscribeFacialSignIn(verificationToken);

    document.getElementById('status').innerHTML =
      'Push notification sent! Please check your mobile device.';
  } catch (error) {
    console.error('Error:', error);
  }
}

Facial Sign‑In API

Web client APIs for application authentication and facial sign-in workflow.

POST/api/v1/facial_sign_on/application_auth

Purpose: Authenticate your web application to get JWT access token for subsequent API calls. 

curl -X POST https://dashboard.axiam.io/api/v1/facial_sign_on/application_auth \
-H "Content-Type: application/json" \
-d '{
  "api_key": "your-api-key-here",
  "secret_key": "your-secret-key-here",
  "domain": "your-domain"
}'
POST/api/v1/facial_sign_on/login/push_notification

Purpose: Send push notification to user's mobile device to trigger facial authentication process.

curl -X POST https://dashboard.axiam.io/api/v1/facial_sign_on/login/push_notification \
-H "Authorization: Bearer JWT_TOKEN_FROM_AUTH" \
-H "Content-Type: application/json" \
-d '{
  "id": "user_uid_here"
}'

ActionCable WebSocket Channel

Purpose: Receive real-time updates when user completes facial authentication on their mobile device.

// Subscribe to receive real-time authentication results
const cable = ActionCable.createConsumer('wss://dashboard.axiam.io/cable');

cable.subscriptions.create({
  channel: 'FacialSignOnLoginChannel',
  verification_token: 'token_from_push_notification_response'
}, {
  received: function(data) {
    if (data.status === 'verified') {
      // User successfully authenticated via mobile app
      console.log('Authentication successful:', data);
      window.location.href = '/dashboard';
    } else if (data.status === 'failed') {
      // Authentication failed
      console.log('Authentication failed:', data);
      alert('Facial authentication failed. Please try again.');
    }
  }
});

Security

JWT authentication, token expiration, and secure API implementation.

JWT Authentication

All API requests require a valid JWT token obtained via the application_auth endpoint. Tokens expire after 7,200 seconds (2 hours) and must be refreshed for continued access.

Token Expiration

Verification tokens have automatic expiration and renewal for enhanced security. Implement secure token handling to prevent replay attacks.

API Reference

Authentication headers, response formats, and error codes documentation.

Authentication Headers

All authenticated requests require the following header:

Authorization: Bearer JWT_TOKEN_FROM_APPLICATION_AUTH

Response Format

All responses follow a standard JSON envelope: 

{
  "success": true,
  "data": {
    "authenticated_token": "jwt_token_here",
    "expires_in": 7200
  }
}

Error Codes

400Bad Request — missing or invalid parameters
401Unauthorized — invalid or expired JWT token
403Forbidden — domain not authorized for this application
404Not Found — user or resource not found
429Too Many Requests — rate limit exceeded
500Internal Server Error — contact support
